Navirado Services

Development and deployment of a business website, including a multi-step booking system, database integration and email automation.

Project overview

Navirado Services required a business website to present its services and support customer enquiries and bookings. My work covered website development, booking functionality, database integration and related digital operations.

Work and implementation

  • Developed and deployed a responsive website using HTML, CSS, JavaScript and PHP.
  • Built a multi-step booking experience and connected booking data to a MySQL database.
  • Integrated the Zoho Mail API for booking notifications and customer confirmation emails.
  • Configured domain and email authentication records, including SPF, DKIM and DMARC.
  • Supported website maintenance, testing, troubleshooting and basic SEO operations.

Technology and tools

HTML CSS JavaScript PHP MySQL Zoho Mail API DNS
