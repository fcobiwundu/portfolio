Mevapay

Full-stack development of a digital wallet application, covering user interface design, frontend implementation, backend functionality, authentication and transaction workflows.

Project overview

MevaPay is a personal full-stack development project focused on building a digital wallet application. My work covers frontend interface development, backend application functionality, user authentication, database integration and transaction-related workflows.

Work and implementation

The project uses Node.js and Express for backend functionality, Sequelize as the ORM and MySQL for relational data storage. The application includes authentication and user management components, dashboard-related functionality and transaction management workflows.

The repository represents the source of truth for the current implementation. Feature details should be checked against the code before describing additional functionality as complete.
