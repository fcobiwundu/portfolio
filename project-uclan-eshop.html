UCLan Cyprus E-Shop

Development of a responsive e-commerce web application featuring product browsing, search and filtering, user accounts, shopping basket functionality, checkout and product reviews.

Project overview

The UCLan Cyprus E-Shop is an academic web development project based on an online student shop concept. The application provides an e-commerce experience where users can browse products, view product information, manage a shopping basket and complete an order.

The application was developed using PHP and MySQL, with PDO for database connectivity. The frontend uses HTML, CSS and JavaScript to provide a responsive interface across desktop and mobile devices.

Key features and functionality

The application brings together several core e-commerce functions:

  • Product catalogue: Displays products retrieved from the database.
  • Product search and filtering: Allows users to search product titles and descriptions and filter products by category.
  • Product details: Provides individual product information pages.
  • User accounts: Includes registration and login functionality using PHP sessions.
  • Shopping basket: Supports adding products and managing quantities through a session-based basket.
  • Checkout and orders: Records submitted orders in the database and clears the shopping basket after checkout.
  • Product reviews: Supports customer reviews with ratings, titles and written descriptions.
  • Responsive interface: Adapts the navigation and page layout for desktop and mobile screen sizes.

Development and implementation

PHP handles the server-side application logic, including user sessions, product retrieval, shopping basket operations and order processing. MySQL provides relational data storage for the application's products, users, offers, orders and reviews.

PDO is used for database connectivity, while JavaScript supports client-side interactions and responsive navigation behaviour.

The application was tested on both desktop and mobile devices, including the responsive navigation menu.

Skills demonstrated

This project demonstrates practical experience developing a database-driven web application, connecting frontend interfaces with server-side functionality and implementing common e-commerce workflows.

It also provided practical experience in responsive interface development, database integration, session management, debugging and testing across different screen sizes.
